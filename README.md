# FocusShare

軽量なデスクトップ向け「集中支援」ツールのプロトタイプです。ユーザーが作業開始前にタスクを宣言し、作業中に最前面アプリや無操作時間を記録、作業終了時に要約・集中度メトリクスを生成します。

## 特長

- 作業セッション管理：セッション開始／終了でタイムスタンプを保存
- 最前面アプリ取得：定期的にフォアグラウンドアプリ名を取得してログ化
- 離席検知：無操作時間で離席を判定して記録
- AI要約の骨子：セッションデータをもとに要約（JSON Schema準拠）を生成可能
- ローカル永続化：SQLiteでタスク・セッション・ログ・要約を保存する想定
